# Vipin Kumar — Portfolio

A minimal, dark video-editor portfolio with a data-driven video section.

## Run

Open `index.html` in a browser, or deploy the folder to Netlify/GitHub Pages.

## Add a new video

Open `script.js` and add an object to the `videos` array:

```js
{
  title: "My New Edit",
  category: "Product / Documentary / Short Form",
  description: "Short description.",
  youtubeId: "YOUR_YOUTUBE_ID",
  featured: true
}
```

The page automatically creates the video card.
